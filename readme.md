# A simple batch geocoder for nyc data nerds

Live at https://www.geocoder.nyc. What's changed, newest first: [WHATS-CHANGED.md](WHATS-CHANGED.md), also published as [a page on the site](https://www.geocoder.nyc/whats-changed.html).

Fueled by [Planning Lab's GeoSearch](https://labs-geosearch-docs.netlify.app/) and Pelias. Inspired by [Erik Willems' Batch geocoder for journalists](https://geocode.localfocus.nl/).

Build using Svelte

## How to setup

Install NodeJS dependencies

```
npm install
```

Run dev
```
npm run dev
```

Build
```
npm run build
```
