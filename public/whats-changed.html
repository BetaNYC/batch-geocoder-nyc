What's changed

This page lists the changes to the Batch geocoder for NYC that a reader would notice: new features, fixes, changes to the address lookup it uses, and corrections when we published something wrong. Newest first. Small updates to the code it runs on are not listed.

  • History begins: 2020-04-19, the day the geocoder went live. Older entries cover only the bigger changes. Corrections made before this date may be missing.
  • Data refresh: none. The geocoder keeps no data of its own. Every address you give it is looked up live in GeoSearch, NYC Planning's address search.

To report a bug in this site or ask for a new feature, open an issue at https://github.com/BetaNYC/batch-geocoder-nyc/issues.

The geocoder moved to version 2 of GeoSearch

January 3, 2023

Tags: Data, Site

Addresses are now looked up in version 2 of GeoSearch, and the building number (BIN) and tax lot number (BBL) in the export are read from that version's answers. A new tip says to add a borough or ZIP code after a comma and to leave out apartment numbers. The street view page's map now credits OpenStreetMap.

The geocoder went live

April 19, 2020

Tags: Site, Data

A free web tool to find many New York City addresses at once. Paste a list or upload a CSV, pick the columns that hold the address, check each match on a map and fix it by hand, then copy or download the results with latitude and longitude.
